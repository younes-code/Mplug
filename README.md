# mplug_owl2

Code for inference and caption generation using VLM models.

## Setup
1. Clone the repo: \`git clone https://github.com/yourusername/mplug_owl2.git\`
2. Recreate env:
   - Conda: \`conda env create -f environment.yml\`
   - Or pip: \`pip install -r requirements.txt\`
3. Install any extras (e.g., VLM-specific): \`pip install transformers torch\` (add if needed).
4. Run scripts, e.g., \`python caption_generation.py\`

## Notes
- Focuses on .py code; data/outputs ignored.
